# EarthOptics

> EarthOptics is a soil data measurement and mapping company headquartered in Minneapolis, Minnesota. It combines proprietary in-field proximal sensing hardware, robotics, genomics and laboratory testing with machine learning to produce high-resolution sub-field maps of soil compaction, fertility and nutrients, soil biology, moisture and soil organic carbon from far fewer physical samples than conventional soil testing. EarthOptics merged with soil-biology company Pattern Ag and reports having mapped more than five million acres of farmland and rangeland.

## API status

EarthOptics has **no public API program**. There is no developer portal, no API reference, no SDKs, no self-serve API signup, and no public API documentation of any kind.

A private REST API does exist at `https://api.earthoptics.com`, backing the EarthOptics 360 PRO customer application. It runs Django REST Framework behind gunicorn and exposes a drf-spectacular OpenAPI schema at `/api/schema/` and a Swagger UI at `/api/docs/` — both of which require a Bearer (JWT) token and return HTTP 401 to anonymous callers. The machine-readable contract therefore exists but is not publicly retrievable, and no OpenAPI document has been captured for this provider.

- API host: https://api.earthoptics.com (unauthenticated `/` redirects to the app login)
- Application: https://app.earthoptics.com/
- Customer login: https://earthoptics.com/customer-login
- Auth: `Authorization: Bearer <JWT>`, `WWW-Authenticate: Bearer realm="api"`
